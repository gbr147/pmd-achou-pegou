Achou? Pegou! Site em desenvolvimento

Projeto escolar · Alpha B3

Um jeito simples de reencontrar o que se perdeu na escola.

Esta página explica o que é o Achou? Pegou!, como o site está organizado e o que cada parte dele faz. A plataforma ainda está sendo construída — o que você vê aqui é a documentação da ideia.

Como funciona

01

Alguém acha um objeto

Um aluno encontra uma garrafa, um casaco ou um caderno pelo colégio.

02

Cadastra no site

Preenche o formulário com nome do item, local e data em que foi achado.

03

O dono pesquisa

Quem perdeu usa a busca da página inicial para procurar pelo item.

04

Objeto devolvido

Com as informações do cartão, o dono recupera o que era seu.

As seções do site

O menu de navegação leva a quatro áreas, todas na mesma página.

Seção 1

Início

#inicio

A porta de entrada do site, com o campo de busca.

  • Mensagem de boas-vindas explicando o propósito da plataforma.
  • Campo de texto “Pesquisar objeto...” para filtrar itens já cadastrados.
  • Botão Pesquisar que dispara a função pesquisar() do script.
Seção 2

Objetos Encontrados

#objetos

A lista dos itens achados, exibida em cartões.

  • A div #listaObjetos começa vazia no HTML.
  • O JavaScript preenche os cartões dinamicamente.
  • Cada cartão mostra nome, local, data e descrição do objeto.
Seção 3

Cadastrar Objeto

#cadastro

O formulário de quem encontrou algum item.

  • Campos obrigatórios: nome do objeto, local encontrado e data.
  • Campo opcional de descrição para detalhes como cor e marca.
  • Ao enviar, o item passa a aparecer na lista de objetos.
Seção 4

Equipe

#equipe

Créditos do projeto escolar.

  • Desenvolvido pela equipe Alpha B3.
  • Projeto acadêmico, sem fins comerciais.
  • Rodapé com a assinatura © 2026.

Equipe Alpha B3

O Achou? Pegou! é um projeto desenvolvido pela equipe Alpha B3 para reduzir o número de objetos que ficam esquecidos na escola. As próximas etapas incluem finalizar a busca, salvar os cadastros e permitir foto do objeto.
