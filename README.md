# PMD Template

Template para o Projeto Multidisciplinar.

## Como utilizar

1. Clique em **Use this template**.
2. Crie um novo repositório chamado:

```
pmd-nome-do-projeto
```

3. Clone o repositório.

```bash
git clone https://github.com/SEU_USUARIO/pmd-nome-do-projeto.git
```

4. Personalize o site.

5. Faça commits frequentes.

```bash
git add .
git commit -m "Descrição da alteração"
git push
```

6. Ative o GitHub Pages.

7. Entregue:

- Link do repositório
- Link do site publicado

## Estrutura

```
index.html
css/
js/
assets/
```
